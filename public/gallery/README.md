# Gallery photos

Each numbered folder is one album page. The gallery reads these automatically.

- Put 2 or 3 images in the folder (jpg, jpeg, png, webp)
- Add the page note in `message.json` as `_message`

Example:

```
public/gallery/Page1/photo-1.jpeg
public/gallery/Page1/photo-2.jpeg
public/gallery/Page1/message.json
```

```json
{
  "_message": "A short note for this page."
}
```
